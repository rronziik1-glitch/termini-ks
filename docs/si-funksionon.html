The app is 3 pieces

Frontend: the shop windowThe pages people seeCalendar, booking screen, your /admin. Runs in the phone's browser.
Backend: the kitchenThe brain behind the pagesChecks free hours, logs people in, talks to Paysera and Claude.
Database: the notebookWhere everything is savedBusinesses, bookings, customers, payments.

Today all 3 run on your PC (that is "localhost"). On launch they move to the rented server in Frankfurt, and people reach them at terminiks.com.

Login

How the code on the phone works

Nobody has a password. A business logs in with its phone number and a 6-digit code, like WhatsApp does.

  1. 1BarberOpens /hyr, types his number, for example 049 111 111.
  2. 2BackendMakes a random code (for example 482 913), saves only a scrambled copy, valid 10 minutes.
  3. 3SMS companySends the code to his phone by SMS or WhatsApp. Today this step is missing, so on your PC the code is shown on screen instead.
  4. 4BarberTypes the code. 5 wrong tries and the code dies.
  5. 5BackendLogs him in for 60 days on that phone. He doesn't need the code again.

Money

How Paysera connects

Termini bookings are free, so no money moves there. Paysera is only for the €100 Faqja Gati page. The app never sees card numbers: Paysera handles the card on its own page.

  1. 1Business ownerPresses "Merre për 100 €".
  2. 2BackendWrites a payment order (amount, order number) and signs it with your secret Paysera password, so nobody can change €100 into €1.
  3. 3PayseraThe owner lands on Paysera's own payment page and pays by card or bank.
  4. 4Paysera → backendPaysera calls our server: "order X is paid", with two signatures.
  5. 5BackendChecks both signatures, the amount and the currency (EUR). If all is right: page marked paid, watermark gone, page live.

AI

What the Claude API is for

Only for Faqja Gati. When an owner writes "barber in Gjakova, 10 years, fades and beards", Claude writes the page's texts (title, services, FAQ, about) in good Albanian and fills Fable's design. Termini does not use it at all.

That small button

The round "N" in the corner

That's a tool of Next.js, the system the app is built with. It only shows while the app runs on your PC in test mode. Customers will never see it online. You can ignore it.
